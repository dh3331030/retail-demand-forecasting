What the results actually say

Plain-language reading: predicting each country’s historical average performed best overall in the test period. Adding macroeconomic variables did not beat that average. Adding weighted conflict deaths worsened the matched forest overall. The differences are descriptive and have not been established as statistically significant or causal.

MAE describes average absolute forecast error. RMSE gives more weight to large errors. Lower is better; both use the target’s log-percentage-point units.
