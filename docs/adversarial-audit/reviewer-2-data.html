Corrections needed before submission

D1 · Report §2.2 gives the wrong index base

Evidence: the supplementary report, PDF page 3 (printed page 2), says the retail series is indexed as “January 2021 = 100.” The registered Eurostat workbook metadata and docs/DATA_SOURCES.md identify Index, 2021=100.

Action: change the description to “seasonally and calendar-adjusted volume index, 2021=100.” The selected annual index base is not January 2021. This correction does not change growth calculations because a common rescaling cancels in the index ratio.

D2 · Report §2.4 blurs annual GED and Candidate coverage

Evidence: PDF page 4 says the study combined yearly conflict data “as of 2023” with monthly releases “for 2024 and 2025.” The actual training source is annual GED 23.1, with event history through 2022. Candidate reference releases cover November 2022-December 2025; the forecasts actually evaluated use reference releases through October 2025, including the 2023 validation period.

Action: explicitly separate the release version, event-reference months, and forecast-target periods. Suggested wording: “Training predictors use annual GED 23.1 for historical events through 2022. Validation and test predictors use historical monthly Candidate releases eligible under the stated two-month rule.” Explain that November-December 2025 Candidate files are included but do not enter the evaluated target months.

D3 · Report §2.5 makes an unsupported claim about COVID's predictive value

Evidence: PDF page 5 says the absence of post-2022 stringency values meant it “added null predictive value.” The final models do not include a controlled COVID predictor comparison. Missing coverage is a reason for exclusion, not an observed zero predictive effect.

Action: keep the defensible statement: COVID stringency was excluded because the supplied source has no recorded values in validation/testing. Remove the inference that its predictive value is zero or that absence establishes that restrictions ended.

D4 · Report §2.1 uses unsupported country characterizations

Evidence: PDF page 3 labels Poland and Portugal “developing European economies,” calls France/Germany sufficiently distant from all conflict sources, and describes relative supply-chain/demographic exposure without presenting the evidence that supports those characterizations.

Action: explain the sample through the directly relevant design: five European markets with different geographic distances to conflict events and available common data. Remove unsupported development and exposure labels unless separately evidenced. Do not confuse a capital-distance proxy with measured national economic exposure.

D5 · Conflict coverage and distance need precise plain-language explanations

Evidence: PDF page 4 describes UCDP as reporting every conflict event on the planet and defines distance in a sentence that omits its two endpoints. The code uses all retained UCDP records and the shortest great-circle distance from each event's coordinates to each focal country's capital. It uses the event start month, rather than every month in which violence remains active.

Action: describe the included UCDP organized-violence records rather than universal event coverage; state the distance endpoints and event-start-month convention. Explain that weighted counts and weighted deaths are continuous exposure indices, not literal local event/death totals.

Limitations that must stay visible, without becoming new last-minute research projects

  • Retrospective information: macroeconomic files are revised 2026 downloads; training conflict records are annual finalized data. Fixed publication delays cannot turn those files into historical real-time vintages. The README and report §3.2 already acknowledge this. Retain that qualification in the presentation.
  • Early test model selection: the full 2023 validation outcome set was not available before the earliest 2024 origins. The test exercise is therefore retrospective even though its monthly fitting cutoffs are implemented. This is disclosed in the configuration, README and report conclusion; do not call the evaluation an exact historical deployment simulation.
  • Conflict source changes: annual GED training and Candidate evaluation differ in revision/completeness. This limits strong interpretations of a small conflict-model performance difference. The project tests predictive accuracy under this construction, not a causal economic effect.
  • Geographic proxy: five hard-coded capital coordinates are transparent assumptions, with no external coordinate provenance recorded. Adding a citation or explicitly naming them as modeling anchors is useful; redesigning exposure before submission is unnecessary.
  • Finite evaluation: five countries over 24 testing months do not provide 120 independent economic experiments. No statistical significance of small error differences has been established. The report correctly avoids such a claim.
