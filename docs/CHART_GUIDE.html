Retail forecasting: chart guide

23 report figures, each available as a 300-dpi PNG and vector PDF. Plots are generated directly inside the existing calculation stages.

Read the figures

Solid blue lines show actual values; dashed orange lines show forecasts. Country panels and models share scales. Growth is measured in log percentage points: 100 × log(current index / previous index). Index history shows adjusted levels instead.

Scatterplot diagonals represent perfect forecasts. Panel labels report RMSE from the current predictions. Lower MAE/RMSE is better. Improvement percentages use the named baseline; positive means lower error. The country and year comparisons use each country’s or year’s own zero-growth baseline. Changes below 0.01% are explicitly marked.

Zero growth remains the validation-selected primary forecast. Test rankings do not select models. Differences are descriptive, without statistical-significance or causal claims.

Regenerate

Open this project in RStudio and run source("run_development.R"), then source("run_final_evaluation.R"). These runners also rerun calculations and fitting. Preserve the frozen configuration and skip the one-time freeze stage. Charts appear in interactive RStudio and always export to results/figures.

Preparation creates index history; target construction creates growth history. Initial validation creates intermediate accuracy and conflict comparisons; reduced-model validation creates the complete 26-model comparison and reduction chart. Final evaluation creates model forecasts/scatterplots and overall, conflict, country and year comparisons.

Verification

All plotting expressions were executed against current saved calculation outputs, without refitting models. Parsed calculation code outside plotting blocks is unchanged. Existing comment lines were compared exactly. Original CSV/RDS hashes are unchanged; recalculated validation/test MAE and RMSE agree within 10⁻¹². Test coverage is six models × five countries × 24 months. Figures were visually inspected; PDFs checked for single-page output.
