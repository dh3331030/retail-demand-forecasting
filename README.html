Retail demand forecasting

This complete project includes 13 original raw Excel/ZIP datasets in data/raw/. The default R workflow reads those files and rebuilds all analytic tables.

How to run

  1. Extract the entire ZIP archive.
  2. Open Retail_forecasting.Rproj in RStudio.
  3. Execute source("00_setup.R") and install any missing packages.
  4. Execute source("run_project.R").
  5. Open results/run_status.json and results/analysis.html.

Terminal: Rscript --vanilla run_project.R or input-only check Rscript --vanilla run_project.R --check.

What is being predicted?

Rolling one-month-ahead growth in food, beverages and tobacco retail volume in Germany, France, Italy, Poland and Portugal. The 2024–2025 evaluation was previously reviewed and is retrospective, not an untouched hold-out.

See data guide, model decisions and detailed run instructions.
