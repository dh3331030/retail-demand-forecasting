Applied forecasting project

Can retail history help predict next month’s demand?

This reproducible R project studies monthly food, beverage and tobacco retail-volume growth in Germany, France, Italy, Poland and Portugal.

Explore the results · Understand the data · Read the model decision

What the analysis does

  1. Checks the supplied source files against their recorded SHA-256 fingerprints.
  2. Rebuilds the retail, economic, COVID and global conflict analysis datasets.
  3. Compares ten one-month forecasting methods using the same country-months.
  4. Reports the results and limitations in plain language and as reusable data files.

Headline result

Across 120 retrospective forecasts for 2024–2025, the full-history ARIMA model recorded a mean absolute error (MAE) of 0.7864. That is about 14.5% lower than predicting no change. MAE summarizes the typical absolute miss; RMSE is also reported because it gives more weight to large misses.

Important: 2024–2025 was examined during earlier model development, so it is not an untouched test set. The results are retrospective and do not establish future performance, real-time data availability, or causation.

Run it locally

Install R and the packages below, then run Rscript --vanilla run_project.R from this folder. Alternatively, open Retail_forecasting.Rproj in RStudio and run source("run_project.R").

install.packages(c("data.table", "readxl", "forecast", "jsonlite", "digest", "ggplot2"))

The analysis uses the supplied files; it does not download data or require API credentials. Package installation requires internet access.

Project files

  • scripts/ contains the data preparation, forecasting, supporting analysis and reporting steps.
  • data/raw/ contains the source extracts; data/source_manifest.csv records their expected size and SHA-256 hash.
  • data/processed/ contains derived observations and analysis panels.
  • results/ contains forecasts, comparisons, figures, validation checks and the generated results page.
  • evidence/ contains selected historical results used to explain the model-selection context.

Data and interpretation

Source dataset names and links are listed in data/raw/project_data_sources.xlsx. The data guide documents units, coverage and known limitations. Source fingerprints verify that the local files match the recorded versions; they do not prove external provenance or historical release timing. Check each data provider’s terms before reusing or redistributing its data.

The forecast is a country-level analytical baseline, not a store-level inventory system. Economic and global conflict measures are supporting context; the model comparison does not establish that they cause changes in retail demand.
